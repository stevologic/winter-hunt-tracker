# Winter Hunt Art Pack: license and provenance

Every model, rig, animation, texture-free material, icon and preview in `AssetPacks/`
is **original first-party work created for Operation Winter Steam Sale**. All of it is
generated by the Python scripts in `AssetPacks/Source/`, which run Blender 5.2 as a
Python module.

* **No third-party content.** No downloaded models, textures, rigs, animations, fonts,
  sounds or AI-generated images are included. Geometry is built from code: primitives,
  metaballs, procedural meshes and analytic animation.
* The preview contact sheets render titles with the game's existing open fonts, Bebas
  Neue and Barlow (SIL OFL 1.1, already in `Game/Assets/_Project/Resources/Interface`).
  The fonts themselves are not redistributed here.
* Rights belong to the project owner. The owner may use, modify and ship these assets
  in the game and its marketing without attribution, and may choose any public licence
  later.
* Replacing third-party placeholders with these assets narrows the game's notice
  obligations. The bear, in particular, is currently CC BY 4.0. Update
  `Docs/AssetCredits.md` and the packaged `Notices` when a swap ships, not before.

Tool provenance: Blender 5.2.2 (`bpy` on PyPI, GPL; tool output is not covered by the
GPL), Pillow, NumPy, CairoSVG and potracer (used only to build previews and icons).
