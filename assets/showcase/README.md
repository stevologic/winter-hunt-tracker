# Original Winter Hunt web showcase

Seven unchanged original GLBs from the Winter Hunt Art Pack at commit
`8c515f28c376ae9f27c40786c5432d24ef321633`, branch `claude/friendly-turing-ozrk6r`
of `stevologic/operation-winter-steam-sale`. `provenance.json` records exact source
paths, sizes and SHA-256 checksums. The original asset names and model/material
names are preserved. See the unmodified source `LICENSE.md` in this directory.
Rights belong to the project owner; inclusion in this website does not grant a
new public license to redistribute the art.

This is a website composition, not a game capture, playable gameplay, or evidence
of integration into Unity. No Unity checkout, process, source, save or build was
used or modified. No purchased assets, third-party raw art or private donor builds
are included. The seven models total 774,108 bytes. One first-party snow BaseColor
texture is resized to 512 x 512 WebP (4,454 bytes); no normal or mask maps are used.
The poster is rendered from this exact Three.js scene with `npm run render:poster`.
It is not an AI image or a captured game frame. Original GLBs are unmodified; the
renderer instances repeated trees and rocks in GPU memory to reduce draw calls.

Three.js is pinned to 0.186.1. Its MIT notice is in `static/three-LICENSE.txt`.
Official references used: https://threejs.org/docs/pages/GLTFLoader.html and
https://threejs.org/docs/pages/WebGLRenderer.html.
